# Synthetic lab

The default lab uses fictional policies, controls, evidence records, and access events. No real secrets, production screenshots, customer data, vendor data, audit evidence, or confidential policy documents are required.

Run:

```bash
python scripts/run_synthetic_compliance_lab.py --controls 42 --seed 42
```

Outputs are written to `outputs/results`, `outputs/reports`, `outputs/figures`, and `outputs/audit`.
