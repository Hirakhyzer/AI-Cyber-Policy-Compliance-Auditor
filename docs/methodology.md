# Methodology

This project uses synthetic controls and evidence to demonstrate a compliance-support workflow.

1. Generate fictional security policies, control owners, implementation status, review frequency, and evidence records.
2. Map controls to high-level ISO 27001-style themes, NIST-style cybersecurity functions, and SOC 2-style trust categories.
3. Score evidence completeness from quantity, quality, freshness, scope coverage, and evidence-type diversity.
4. Combine inherent risk, implementation posture, mapping confidence, evidence completeness, and review age into a compliance gap score.
5. Generate remediation prompts and a Markdown report for human review.

All scores are transparent heuristics intended for research and triage, not official compliance decisions.
