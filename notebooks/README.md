# Notebook guidance

Use the Python modules in `src/cybercompliance` after running the synthetic pipeline.

Suggested cells:

1. Load `outputs/results/synthetic_control_inventory.csv`.
2. Load `synthetic_framework_mapping.csv`, `synthetic_evidence_audit.csv`, and `synthetic_compliance_gap_audit.csv`.
3. Inspect highest-priority controls.
4. Compare evidence completeness by control owner.
5. Review remediation actions and access-review flags.

Do not upload confidential policies, real audit evidence, customer data, credentials, or secrets into notebooks unless proper authorization and governance are in place.
